# Semgrep OSS source availability

AI Security Runtime invokes Semgrep OSS 1.178.0 as a separate Python package and subprocess. The corresponding upstream source for that pinned engine is available at https://github.com/semgrep/semgrep/tree/v1.178.0 and from the release archive at https://github.com/semgrep/semgrep/archive/refs/tags/v1.178.0.tar.gz . The full LGPL-2.1 license text shipped with this Runtime is at `src/security_runtime/licenses/semgrep/LICENSE`.

Distributors must review the LGPL obligations for their actual delivery format and provide the corresponding source and notices required by that format. This document records the pinned upstream source; it does not replace those obligations.
