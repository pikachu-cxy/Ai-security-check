# 可移除的本机实时消耗页面

更新日期：2026-10-21。本页对应 0.3.9 源码；安装包公开状态以对应 Release 资产为准，0.3.8 旧包不自动获得新增入口。

页面是手动启动的独立本机进程，每 2 秒读取统计。它不扫描项目、不请求模型、不启动检查或修复，也不随 Runtime 自动运行。本机正在使用源码启动页面，已安装的 Runtime 继续提供原有服务。

## 先看清这些数字属于谁

| 页面数据 | 实际范围 | 不能推出什么 |
| --- | --- | --- |
| 选定聊天总 token | 这一份聊天日志中的最后累计宿主用量，包含讨论、开发、核查及历史上下文反复输入 | 不能当作产品扫描 token，也不能当作全项目或所有聊天总量 |
| 纯开发 / 产品扫描 token | 尚无可靠的活动与模型用量关联，显示“无法拆分” | 不能用工具字节估算，不能用聊天总量减去某一工具得到开发消耗 |
| Runtime 工具累计响应耗时 | 所选保留记录中的每次 MCP 响应前耗时之和，使用单调时钟 | 并发会重叠，不是用户等待或纯扫描器时间 |
| 显式扫描入口 | 仅 scan_diff、scan_project、scan_files 的调用与响应耗时，包含失败、中断和复用请求 | 不等于成功扫描数；finish_security_task、Hook 等入口也可能在内部扫描，零条不证明没有扫描 |
| 核查 / 复核流程入口 | 按公开工具名称归类的任务、证据、提交、Hook、验证等入口 | 不是纯开发消耗，不能从中拆出引擎、存储或模型用时 |
| 工具占用时间 | 有详细起止记录的工具区间并集，扣除并发重叠 | 不覆盖无起止时间的旧基础记录，也不是完整任务时间 |
| 首末工具跨度 | 最早开始到最后结束，包含中间空隙 | 空隙不能推定为模型或排队等待 |
| 手动观察窗口 | 从点击开始至结束的单调时钟时长，结束后固定；期间聊天计数取前后差 | 包含期间所有活动，不是自动识别的产品安全任务，不排除其他聊天的共享连接调用 |

输入 + 输出 = 总 token；缓存输入包含在输入中，推理输出包含在输出中。页面没有计费计算。扫描器内部时间、模型处理、网络和锁/队列等待缺少独立证据时显示未知。

宿主用量按批更新，页面显示最新已报告的计数及更新时间；尚未结算的生成不会逐 token 出现。手动窗口以前后最近可读计数作差，不承诺精确到点击瞬间的 token 边界。

## 启动与查看

### 一键试用（0.3.9）

在已连接更新后 Runtime 的 Codex 聊天中说“启动本聊天的消耗监控”。Agent 使用
`start_usage_monitor` 和已有会话路由打开浏览器，自动开始观察。试用者无需输入命令、
查找日志或设置采集标签；结束后点 **结束并导出报告**，下载包含 HTML、JSON 和说明的 ZIP。
当前运行中的旧 MCP 进程需要重新连接才能发现新入口；源码更新与公开安装包分开核对。

自动关联使用现有 Hook 会话引用验证工作区和会话，再匹配日志文件名与首行会话元数据。
不按最近时间选聊天，不读取其他聊天正文。同一身份有多个候选、日志缺失、宿主不支持、
身份验证失败或工作量超过发现上限时明确不可用。当前仅实现 Codex 本机日志适配。
从当前 Codex 聊天的工具终端启动时，也可用 `security-check context-usage start`；
它需要宿主提供 `CODEX_THREAD_ID`，普通桌面双击没有当前聊天身份时不会猜测。

报告 token 是起止最近已报告的本聊天计数差值，包含期间开发与核查；未结算用量可能尚未包含。
新聊天启动时没有用量基线的，首个可读计数之后开始累计，并明确起始部分缺失。
工具耗时仅归入通过现有会话校验的调用，其他项目调用单列；不把共享 MCP 连接等同于聊天。
没有会话参数的显式扫描等入口可能仍未关联；报告保持部分覆盖，不能称纯安全 token。
导出不会保存聊天正文、源码、日志路径、原始会话 ID 或会话引用。ZIP 由浏览器下载，
重复导出保留同一结束快照；新观察窗口重新计量。

监控仅为当前聊天建立有期限的详细记录租约，不改写共享采集模式；全局关闭仍优先。
结束导出、停止页面或后台进程退出时释放，意外退出最长 8 小时失效。启动、关联和统计
错误不改变扫描、开发核查和权限结果。`monitoring/` 及现有可选统计文件可整体移除，
核心只保留捕获异常的可选调用，MCP 启动入口缺席不影响其他产品工具。

### 原有手动入口

在仓库根目录的源码开发环境启动，显式指定项目和当前聊天用量文件；参数中的项目仅作为统计筛选，不是扫描目标：

```console
PYTHONPATH=src .venv/bin/python -m security_runtime.monitoring --project /absolute/project --chat-log /absolute/current-chat.jsonl
```

包含该模块的构建也可使用：

```console
security-check context-usage dashboard --project /absolute/project --chat-log /absolute/current-chat.jsonl
```

Windows PowerShell 的源码入口为：

```powershell
$env:PYTHONPATH = 'src'
.venv\Scripts\python.exe -m security_runtime.monitoring --project 'C:\absolute\project' --chat-log 'C:\absolute\current-chat.jsonl'
```

打开启动时打印的完整本机网址。默认随机空闲端口和随机访问路径，仅监听 127.0.0.1；不使用外部资源、CDN、网络服务或新依赖。重启通常生成新网址。未指定聊天文件时 token 保持未知，仍可看 MCP 数据；不自动搜索其他聊天。32 MiB 文件 / 1 MiB 单行限制下，增量读取已完成行，文件替换、截断、身份改变或累计计数回退会明确显示不可用。

导航范围：

- **监控总览**：统计库的全部有效保留 MCP 记录；token 单列为选定聊天累计，两者范围不同。
- **当前聊天**：选定日志的实际 token。当前 MCP 记录没有可信聊天关联，工具数据保持“未关联”。
- **扫描入口 · 产品工具**：仅保留的三类显式扫描入口，跨项目与采样组；不覆盖核查或 Hook 内部扫描，token 不分配到扫描。
- **当前项目 · 已关联**：工具按明确项目参数的哈希关联；token 仅为选定聊天中连续同项目的已观测增量。首个基线、跨项目边界、其他聊天均不补计，不能称项目全量。
- **任务观察窗口**：点击“开始新窗口”，工作结束后点击“结束窗口”。观察窗口及其基线只存在于页面进程内；结束后 token 差值和时长固定，重启不恢复。它不创建产品安全任务。

旧构建可能没有全局路由项目参数关联，历史工具记录可能全部未关联；启动新页面不会补造历史关系。新源码采集器只读取有界的绝对 workspace_path 作为归属元数据，存储其哈希，不把用户参数当成权限证明。

## 开关与停止

右上方 **MCP 记录** 控件：

- **关闭**：停止自动写入后续 MCP 统计，保留历史。
- **基础统计**：记录调用、字节和耗时，不增加起止时间线。
- **详细调试**：记录后续调用的起止时间，可查看明细和并发流程。

模式保存在独立统计库，使用同一库的 Runtime 后续调用即时读取。它影响同库其他连接，不是聊天私有开关。环境变量可能覆盖保存设置，以显示的实际模式为准。**此控件只控制 MCP 采集，已选聊天的宿主计数读取仍会继续。**

**暂停刷新**仅暂停页面请求。**停止页面服务**或启动终端的 Ctrl+C 会停止监控进程，不停止 Runtime，不改变采集模式；如要同时停止采集，先选择“关闭”，再停止页面。导出当前数据只下载脱敏后的本次快照，不导出聊天正文或原始日志。

命令行控制和离线导出见[消耗监测指南](CONTEXT_COST_MONITORING.zh-CN.md)。

## 依赖与移除契约

依赖方向：`可选页面 → 统计读取适配器 → 独立统计库 / 显式聊天文件`。产品扫描器、任务账本和业务界面不依赖页面；页面不写业务数据库、项目配置或宿主配置。手动窗口在内存中，趋势最多 240 个点，明细最多 1,000 行并显示省略量。

核心集成只有可选 CLI 注册和可选 MCP 响应观察器。模块缺失、导入失败或观测结果解析失败时，原工具结果与产品启动继续。采集与统计库存取失败不会阻止正常工具返回。只读请求不创建缺失的统计库。

移除方式：

1. 日常使用直接停止页面，或关闭 MCP 采集；产品继续工作。
2. 从源码交付中整体移除 monitoring/ 与 context_cost*.py、context_report.py、codex_usage.py、token_usage.py 后重新合法构建；核心入口仍可启动并列出产品工具。不要直接删除受管安装包中的文件，受管包仍遵守内容身份校验。
3. 统计库可独立保留供以后导出；移除功能不需要迁移或清理产品状态。

本轮定向验证 **72 passed**，包含真实删除模块后的启动、异常隔离、保守归属、累计值去重、窗口冻结、回环访问与来源校验、模式切换及只停止页面服务。HTTP 测试最初被本机代理改写 Host 返回 502；测试客户端显式直连回环地址后通过，服务校验未放宽。浏览器实测与真实数据仅在本机 macOS 完成；Windows 使用同一标准库实现，源码示例不等于 Windows 实机验收。

本轮没有改动扫描、复核、缓存、压缩或调度策略，没有实施性能优化。后续先补齐同一操作的活动身份和内部阶段证据，再决定如何拆分开发、产品扫描与等待的真实消耗；没有证据的历史记录继续保持未知。
