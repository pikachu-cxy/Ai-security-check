## Windows 原生引擎临时目录修复（2026-10-19）

socketpair 的后续对照区分了两个触发条件：工具沙箱禁止本地通信，以及此前隔离测试设置的长 TEMP/TMP。普通用户权限下使用默认短临时目录时，原 25 项语料曾复测通过；保留 105 字符临时路径则能稳定复现原生缓冲区错误。这不是所有 Windows 机器都失败的证据。

产品适配已拆为私有目录 OS 原语、调用级子进程环境、合成执行探针；BaseScanner 在有效环境中完成原有执行身份校验。Semgrep 的 Windows 就绪判断增加有界原生扫描，复用成功缓存，失败保留组件及明确诊断。创建后的扫描输入根重新规范化并验证，修复相关路径映射造成的清理登记不一致。系统环境、沙箱权限和其他引擎保持各自原有边界。

本轮已在原 105 字符 TEMP/TMP 条件下实测 **25 passed / 30.47 秒**；冻结源码后另对 20 文件回归 **411 passed、1 skipped、0 failed / 272.76 秒**，合计 436 项通过、1 项因账号符号链接权限跳过，属于定向回归。初次失败及修正记录以[当前验收记录](RUNTIME_CHAIN_REGRESSION_ACCEPTANCE.zh-CN.md#windows-socketpair-产品修复)为准，不把历史 751 项结果直接当作本次新增代码通过。
