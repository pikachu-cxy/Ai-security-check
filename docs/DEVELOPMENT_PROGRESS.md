## 2026-10-16：任务会话隔离修复与源码同步

任务现在按签名会话引用或当前 MCP 连接分别建立，工作区中的旧活动任务不再阻止新会话；Hook 不按最近任务归档，跨会话写入和关闭被拒绝。重连可使用原引用和有效会话引用继续，不能在编辑后重建开始版本。重叠任务保留改动归属缺口，历史风险不清空；命令 Hook 的短进程退出不作为聊天已结束的证据。编辑时只读取活动任务，避免反复解析已完成任务的大型上下文。

本批同步范围包含此前第 6、7 轮规则与缓存优化，以及本次任务生命周期修复；不包含另一个会话尚在开发的组件健康、许可清单和提示文案改动。通过独立索引和源码副本验证，保留主工作区和其他会话的未提交修改。详细机制与验证边界见[任务会话修复报告](design/TASK_SESSION_OWNERSHIP_20261016.md)。本批只同步源码，不创建版本标签、安装包或重启正在运行的连接。

独立集成首轮的 3 个旧断言已修正并通过专项重跑；最终相关覆盖为 458 项测试、6 个 subtest 通过，2 项平台相关测试跳过。当前连接未取得本轮独立编辑前核查基线，自动任务安全核查仍未完成，不能用回归测试代替这一结论。
