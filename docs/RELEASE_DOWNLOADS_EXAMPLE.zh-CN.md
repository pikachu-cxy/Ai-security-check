## 下载安装包

按电脑类型点下面的下载入口，解压完整包使用；无需安装 Python。

| 下载入口 | 怎么选 | 校验 |
| --- | --- | --- |
| **[下载 Windows x64](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-windows-x64.zip)** | Windows 64 位电脑 | [SHA256](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-windows-x64.zip.sha256) |
| **[下载 Mac Apple Silicon](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-macos-arm64.tar.gz)** | M1/M2/M3/M4 等 Apple 芯片 | [SHA256](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-macos-arm64.tar.gz.sha256) |
| **[下载 Mac Intel](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-macos-x64.tar.gz)** | Intel 芯片 Mac | [SHA256](https://github.com/pikachu-cxy/Ai-security-check/releases/download/v0.3.4/ai-security-runtime-v0.3.4-macos-x64.tar.gz.sha256) |

Mac 在「关于本机」查看芯片；也可运行 `uname -m`：`arm64` 选 Apple Silicon，`x86_64` 选 Intel。
