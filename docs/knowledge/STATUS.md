# 当前功能状态与目标

核对日期：2026-11-05。源码版本以 `src/security_runtime/_version.py` 为准，当前为 `0.3.13`。知识库依据当前工作区（含未提交源码）构建，不表示某个发布包或本机连接与工作区完全一致。此页只维护当前实现、目标与验收边界。

## 统一目标

在尽量降低开发等待的前提下，发现本次开发涉及的风险，并保留输入版本、证据、覆盖限制与用户决定。提速不能靠省略完整性校验、漏掉候选、扩大授权或把未完成写成完成。

## 能力矩阵

| 能力 | 当前实现 | 验收边界及下一步 |
| --- | --- | --- |
| 轻量开发检查 | 已有路径记录、文件监听、收尾后台检查、原引用查询与等待 | 默认无全项目基线；未知范围、删除语义及组件覆盖不足继续保留 |
| 扫描引擎 | OpenGrep、Gitleaks、Trivy 适配及原生有界分析器与归一化已实现 | 规则适用性、依赖数据、平台及组件状态决定实际覆盖；不宣称全语言完全覆盖 |
| 宿主分析 | 扫描候选与业务审计分别保存，使用实际证据引用 | 默认开发复核由宿主 Agent 执行；按配置分别 REQUIRED 或 SKIPPED_BY_CONFIG。独立 BYOK 通道需另行明确授权代码外发 |
| 风险处置与修复 | 技术判断、用户决定、修复准备和原问题复查分离 | 不自动修复；保存成功不等于整个审计完成 |
| 严格任务复核 | `tasks/` 与 `task_review/` 提供 v3 证据与覆盖流程 | 只在明确请求或继续原严格任务时使用；不能在编辑后补造基线 |
| Codex 接入 | 全局 MCP、Hook、Skill、工作区会话路由已实现 | 接入实现不等于当前宿主连接成功；验收时读取实际构建身份与工作区会话绑定 |
| Cursor 与 WorkBuddy 接入 | 存在各自安装、Hook 与配置适配器，复用交付流程 | 源码存在与隔离安装通过不等于各桌面宿主最新构建已完成全场景验收 |
| 原生安装与升级 | 清单校验、并行校验与复制、启动器迁移及实际身份核验已实现 | 排除下载后 ≤10 秒仍为待验收目标；须使用当前原生包测量首次、重复和升级，不能从源码或旧测量推断达标 |
| 性能测量 | 安装、MCP、扫描和复核区间有测量入口 | 服务端调用时间不等于模型思考或整个聊天时间；后两者缺少宿主时间戳时保持未知 |
| 工具参数诊断 | 原始参数校验、分组路由与复核提交字段诊断存在 | 知识库构建不替代对应源码的专项回归或性能验收 |
| 跨平台交付 | 构建、安装与发布脚本存在 | 本机 Windows 成功不能替代 macOS 或其他用户机器验收 |

## 安装状态的判定

知识库不固化某台机器或某个聊天的连接快照。验收需分别核对源码/包身份、实际启动器身份、当前 MCP 连接身份及工作区绑定；组件和漏洞数据就绪度单独查询。已有安装回执或同版本号不能替代这些当前状态。
