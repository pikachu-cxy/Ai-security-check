# 当前功能状态与目标

核对日期：2026-11-05。源码版本以 `src/security_runtime/_version.py` 为准，当前为 `0.3.13`。知识库依据当前工作区（含未提交源码）构建，不表示某个发布包或本机连接与工作区完全一致。此页只维护当前实现、目标与验收边界。

## 统一目标

在尽量降低开发等待的前提下，发现本次开发涉及的风险，并保留输入版本、证据、覆盖限制与用户决定。提速不能靠省略完整性校验、漏掉候选、扩大授权或把未完成写成完成。

## 安装状态的判定

普通开发源码已采用轻量收尾、合并复核指导、默认摘要和按需历史。原生引擎版本探测使用固定工作目录复用已有缓存；实际扫描的输入与执行身份仍独立校验。源码变更不代表已更新本机安装版本，耗时需用对应构建重新测量。

知识库不固化某台机器或某个聊天的连接快照。验收需分别核对源码/包身份、实际启动器身份、当前 MCP 连接身份及工作区绑定；组件和漏洞数据就绪度单独查询。已有安装回执或同版本号不能替代这些当前状态。

## 开发收尾的 Git 忽略规则

收尾只对本轮记录路径运行 Git check-ignore，排除 Git 实际忽略的未跟踪文件，支持嵌套规则和否定规则；已跟踪文件继续检查。不盘点全仓库。查询失败保留全部路径，状态记录 GIT_IGNORE_FILTER_UNAVAILABLE。被排除路径记录在 gitignored_paths。这是扫描范围规则，不证明文件是临时产物；未暂存、未提交、未跟踪均不等于临时文件。该实现已纳入原生构建验证；具体环境是否生效须核对实际连接构建。

## 开发记录及失败收尾

开发路径记录不再限制路径数量或累计路径名称字节数；保留路径合法性、去重与历史缺口，不扩大为全项目扫描。此变更不取消独立扫描输入大小、进程超时和并发任务边界。失败终态在同一检查输入版本上只保存一次非阻塞 Stop 提示，跨重连复用，不自动重扫、不标记交付成功。

原生包必须携带 go_sql.py 和 flow_core.py 的实现字节，供 Go 规则身份计算。缺失前者会在 Go 规则规划时触发 FileNotFoundError，与路径记录超限是独立问题。规则规划错误仅记录扫描器、固定阶段与对象类别，不保存私有文件名。源码回归、安装包验证与驻留连接身份分别核验。

当前修复在 macOS 完成 90 项核心回归和 13 项原生监听回归；1,501 条长路径记录完整保留。隔离 Go 样例在旧包复现资源缺失，新原生包完成扫描。失败通知去重、路径限制移除和 Git 忽略过滤已进入同一原生构建。上述结果不代表跨平台验收或全项目安全检查通过；候选复核完成仍须保留静态覆盖缺口。

扫描与复核耗时的当前测量口径、样本及优化顺序见 [性能分析](PERFORMANCE.md)。

## 开发结果统一存储
