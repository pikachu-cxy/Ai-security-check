## 1. 后台入口与完整回复

在 Codex 说“打开风险统计”。应只返回本机授权链接，不主动打开浏览器、扫描项目或创建全项目基线。首次点击授权后保留固定页面。重启产品再打开，应仍为同一端口；同一项目会话的收尾链接参数应保持一致。

分别沿原三个场景开发：无漏洞、依赖/密钥/代码多类风险、真假 SQL 混合。检查回复保留开发结果，确认项逐项有漏洞名、评级来源、路径行号、问题、影响、建议和未知项，末尾一个本会话链接。误报数量应与保存记录一致，不能重复保存为两个独立确认项。不要因为打开风险页而重新扫描。

## 左侧分组导航

源码范围验收：在已有项目执行依赖安装，仅安装目录和编译文件变化时应无待扫描源码；同时修改源码、配置、依赖清单或锁文件时仍检查这些修改。普通 `src/runtime` 不应被排除，改名为 `.so` 的文本仍保留。旧失败记录不自动变成成功，在重启后的新开发批次验收。

左侧分为安全运营、资源管理、系统管理。点击标题或用键盘 Enter/空格展开、收起，子页面缩进并高亮当前项。首次进入展开安全运营；进入项目、工作区、会话或设置时自动展开所属组。项目 → 工作区 → 会话的原有筛选联动继续保留。窄屏仍可展开分组并访问全部入口。导航折叠只改变页面显示，不调用扫描或 Stop。

## 2. 列表、详情与处置

点击会话链接，确认只显示该项目/worktree/会话；切换全部风险后可查看其他会话。按类型、评级、状态筛选，页数和统计应采用相同范围。详情首屏应显示完整路径、行号、代码高亮、问题、影响和建议；原始报告、规则、历史和管理表单折叠。代码摘要匹配时注明与记录版本一致，变化后保留历史片段并折叠当前代码，文件缺失如实提示。不能把代码展示当作重新扫描验证。

选择测试风险：填理由暂缓，刷新核对；撤销恢复；标记误报，刷新核对原 Agent 判断仍保留。修改备注、负责人、人工评级和影响后再打开应保留。选多项批量归档，再到已归档筛选恢复；原证据不能丢失。两个窗口同时编辑同条记录时，旧窗口应报版本冲突而不覆盖新值。

修改曾标误报的测试文件并正常收尾，原用户处置应失效并重新提醒；查看历史仍能找到原理由。人工新增必须选已有项目并用相对文件路径，默认待确认，不自动当作已证实漏洞。

## 3. 导出和设置

对同一筛选导出 JSON、CSV、SARIF，文件条数对应全部筛选结果而非当前 50 条页面。JSON 保留产品元数据，SARIF 保留位置/规则/判断扩展，CSV 能直接用于汇报。密钥证据应脱敏。读取范围不完整时应拒绝冒充完整导出。外部平台上传目前不验收。

在产品设置关闭扫描候选复核、业务审计，保存后在新一批开发中测试：仍应完整交付静态候选，标为未经 Agent 确认，不主动复核。重新打开扫描候选复核后新批次恢复；已开始批次沿自己的旧配置。无效规则路径组合、负数限制或旧配置版本应拒绝保存。

## 4. 修复任务

在确认的测试漏洞上点“交给原会话修复”，刷新看任务状态；重复点击不创建多个执行。回到同项目原 Codex 会话继续操作，应收到该风险的修复交接。先核对影响和证据，再沿已有准备及验证流程修复。仅保存请求不能显示已解决。原会话离线时任务继续待执行，可复制详情中的指令回到原会话；不把另一个会话当成原 owner。尚未领取时可以取消。

## 5. 开发期业务审计

设置开启业务逻辑审计，选择“先交付已完成结果”，从新批次开始一个含权限/对象归属检查的功能任务。期待在开发过程中派发只读子 Agent，主开发继续；Stop 汇总已完成结果和未审范围。页面能区分运行、完成、需补审、中断或不支持，不能一律显示安全。

子 Agent 分析期间继续修改相关文件：旧 dirty_seq 不得保存，取消旧任务后补审。修改已读权限依赖后，原结果不得被当作当前证据复用。模拟关闭会话、超出任务预算，状态应保留未完成；恢复后由宿主重新准备。切换等待策略另测有界收集，不得无限续接。

打开两个 worktree 的同名文件，确认项目归并、工作区和修复任务隔离。同会话工作区一个在途审计，全机最多两个；额外任务应明确预算限制而非伪造完成。

## 验收记录口径

记录实际安装构建、宿主、配置版本、检查序号、候选/确认/误报/重复数、首次保存是否成功，以及扫描、Stop 剩余复核、最终回复耗时。只读已有验收记录，不因统计而重扫。当前自动化回归和合成性能结果见产品方案与性能记录；用户这轮的真实聊天总耗时、token、取消行为和完整宿主交接仍须以实际记录判定。

刷新页面确认左侧有仪表盘和四类资源管理，无检查批次筛选。在隔离测试项目中删除一项，确认对话框数量准确、列表与图表同步减少；回收站恢复后数据重新显示。后续新检查不能因旧删除被永久隐藏。仪表盘分别检查扫描组和确认组的类型数量及占比，扫描误报只进入扫描组，未确认项不进入确认组；两组不能相加。
