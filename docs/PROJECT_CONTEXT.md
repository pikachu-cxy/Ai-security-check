# 项目上下文

更新日期：2026-10-15。本页提供恢复开发所需的稳定事实，具体进展以[开发进度](DEVELOPMENT_PROGRESS.md)为准。

## 产品与版本

- 产品为 AI Security Runtime，当前源码版本 0.3.4，处于 Developer Alpha。
- 当前开发分支为 feature/runtime-mvp；源码同步、公开发行和本机安装是不同状态。
- 许可目前为核心专有、部分规则和接口开放；免费个人版不等于 Runtime 整体开源，见[许可说明](../LICENSING.md)。

## 核心流程

宿主事件进入适配层，由 Runtime 管理工作区、版本、检查、发现身份、修复授权和原问题复查。
宿主 Agent 负责受限上下文分析及已获批准的代码编辑。宿主能力声明、模型判断、测试回执与扫描证明分别保留。
用户必须先选择并批准具体修复；旧 smart_auto 配置或发现严重度不授予修复权限。

日常开发聚焦必要范围和低打扰反馈；普通聊天结束不启动全库扫描或额外开发任务。
代码变化、缺失证据、部分覆盖和未完成检查应明确显示，不能据零发现宣称项目安全。

架构和契约见[整体架构](ARCHITECTURE.md)、[核查契约](design/SECURITY_REVIEW.md)与[任务核查设计](design/TASK_SECURITY_REVIEW_DESIGN.zh-CN.md)。

## 验证与交付规则

- 定向源码测试不能替代完整 CI、原生包或真实宿主使用。
- 冻结候选后记录源码提交、构建身份、检查工具／规则／数据版本和实际覆盖。
- 当前功能隐藏组 281 项通过、2 项跳过；补充启动／并发组 80 项通过、1 项跳过，与前组存在重叠，准确范围见开发进度。
- 先前整任务安全核查受文件盘点预算限制而未完整完成；同步文档或推送代码不改变这项事实。
- 原始日志、测试项目、缓存、安装包和扫描数据库不进入 Git 文档；仅保存必要脱敏结论。
