## 产品与职责

AI Security Runtime 在本机管理工作区、真实开发基线、静态扫描、发现身份、用户处置、修复准备和原问题复查。宿主 Agent 负责有界代码推理及用户授权范围内的修改。Runtime 不调用宿主模型，扫描器命中不自动等于真实漏洞。

个人版覆盖检测、解释、选择、授权修复与安全复查。功能验证默认入口隐藏，复杂功能回归、团队治理等属于后续企业规划。用户原任务包含的测试照常执行，不能因安全检查状态额外扩大执行范围。

核心仍为专有许可，部分规则和接口另有许可；免费个人版不等于整个 Runtime 开源。见[许可](../LICENSING.md)。

## 当前架构

Codex / Cursor 输入适配 → 公共事件及工作区应用服务 → 原任务与扫描服务 → 固定私有输入 → 同一扫描引擎 → 按原版本条件发布 → 风险处置与有界结果交付。

本次修复为 Windows 输入使用短的用户私有根，初始化成功才发布执行占位；完成事实在发布锁繁忙时按原尝试恢复。当前交付和历史共用分页器，当前交付要求原会话、完成修订与当前源码；历史查询无主动处置选择。静态与宿主发现采用同一当前处置投影，读取失败保留详情并标记未知。

## 不可混淆的状态

| 事实 | 含义 |
| --- | --- |
| 连接工具可用 | 不证明项目已经扫描 |
| 静态检查零发现 | 不替代 Agent 必需代码复核，不证明整个项目安全 |
| AI 判断误报 | 需要当前具体反证，与用户决定分别保存 |
| 用户排除/暂缓 | 控制提醒，不是已修复或已验证安全 |
| 新任务检查完成 | 不自动关闭原任务的旧风险 |
| 历史 COMPLETE | 保留当时状态，不证明适用于当前源码 |
| GitHub 已同步 | 不自动发布安装包、重启当前 MCP 或更新安装 Skill |

开发任务只执行 v3；旧协议历史不迁移、不补造修改前源码。会话归属、原引用、证据与累计预算不能借重连或新任务替换。
