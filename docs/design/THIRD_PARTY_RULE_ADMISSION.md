# 第三方规则内置准入

默认分发内容限定为自写规则，以及逐条完成许可、质量和来源核验的第三方规则。
规则先在隔离副本中评估；2026-10-16 经差异核对合入当前源码，未安装或重启全局安全服务。

## 每条规则必须保留的记录

- 原始发布者、仓库 URL、固定提交、原始文件路径和 SHA256。
- 文件级许可声明、适用的父目录 LICENSE、根 LICENSE、例外条款及版权人。
- 衍生来源和其他组件的许可；根目录写着 MIT 不代表所有子目录都能采用。
- 原文许可、版权声明、修改说明以及产品第三方声明中的对应入口。
- 可再分发、商业使用、修改和服务用途的明确许可依据；不能用免费、开源或个人版名称替代授权。
- 本地基准和独立正反例的结果，以及本轮是否默认启用。

无法确认来源或有冲突的规则不进入默认包。Semgrep Rules License、Commons Clause 和其他受限规则可在其许可范围内做本地对照，不能自动并入可再分发规则集合。
符合许可但存在新增误报或没有可验证增益的规则，也不因“能分发”而直接启用。
不要把第三方规则标成自写，也不要仅修改 id、文字或 YAML 排版就去除原许可与来源。

## 与并行开发的隔离

评测时的候选源码固定在 `.tools/rule-quality-20261016/candidate-r5/`，评估进程通过进程级 PYTHONPATH 选择此副本。
不编辑全局环境变量、MCP/Hooks 配置，不安装依赖，不重启其他聊天的服务，不替换共享的 src/rules。
扫描按项目串行，Semgrep 最多两个工作进程；仍会占用少量 CPU 和磁盘，不能保证性能完全没有影响。
合入时须比对原始文件哈希；发现共享文件变化就保留补丁并重新核对，不覆盖其他聊天改动。
