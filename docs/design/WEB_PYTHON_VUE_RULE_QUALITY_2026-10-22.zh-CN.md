# JS/TS、Python 与 Vue 规则质量验证

本轮源码规则包为 `ai-security-core 1.5.0`，70 条独立规则、62 条默认启用。规则默认随仓库交付，继续允许用户用 `--rules` 配置本地目录；没有增加在线更新服务。

## 实现范围

- JS/TS 新增请求输入到 `eval`、`Function` 和 Node `vm` 代码参数的污点规则。显式导入 Express `Request` 的处理器补充 SQL、命令和删除路径来源。新代码执行规则不假定未知函数返回值继续携带污点。
- Python 新增显式 `sh/bash/dash/ksh/zsh -c`、`cmd /c` 的命令槽规则，包含紧邻列表构造/append 和受限平台分支。普通 argv、命令覆写、`executable` 覆盖和标准数值转换有反例。未改变 Python 跨文件范围或原有常量证明。
- Vue 提取顶层 `<script>` / `<script setup>` 的 JS/TS，独立扫描每个块并映射回原始 UTF-8 字节位置。模板、样式、外链脚本、不支持的语言和脚本块之间的传播均未覆盖。
- 轻量数据流复用 Semgrep 局部污点能力，补足来源、传播和安全用法的验证。结果分别标明污点分析依据、静态范围及路径是否实际提供；只保留有界脱敏元信息，没有新增全项目调用图或运行时检测。

未知函数返回值、框架模型查询和任意包装器仍是边界。当前 Semgrep 1.178.0 离线实际输出未提供 `dataflow_trace`，已如实记录 `NOT_PROVIDED`；不能把规则命中说成完整传播路径。

## 回归门禁

- 全部 70 条内置规则：242 个正例、228 个反例，精确位置匹配通过。
- JS/TS 实际适配器：42 个隔离案例，18 个正例、24 个反例通过；包含赋值、拼接、安全覆盖、SQL 绑定、普通 argv 和固定 URL 主机。
- Python 新规则：8 个风险、15 个安全样例通过；固定 92 文件三轮结果一致。
- Vue 实际适配器：8 个内置案例、2 个用户本地规则案例通过。两个内置命中与一个自定义命中保持原文件路径、行列及原字节哈希；双块隔离、模板文本、固定覆盖和未支持输入符合预期。
- 单元回归覆盖元信息脱敏、缺失路径不编造、引擎失败、预算、同一文件部分块失败、路径过滤规则、快照竞争及语言执行证据。
- 最终相关回归：665 项通过、12 项按环境条件跳过，另有 6 个子测试通过；结果见本地 `final-regression.txt`。跳过项不算已验证。

可重跑入口：`scripts/test_rules.py`、`scripts/test_javascript_rule_product.py`、`scripts/test_vue_rule_product.py`。本轮本地结果位于 `.tools/web-rules-round4-20261022/`；Python 三轮整合记录位于 `.tools/python-shell-round4-20261022/integrated-comparison.json`。这些本地记录不是发布包或永久 CI 制品。

## 明确边界

Vue 总体最多标为部分覆盖；没有支持脚本则未覆盖。一个块失败不抹去另一个成功块的证据。带 `paths.include/exclude` 的本地规则暂不投影 Vue，并说明不支持原因，防止临时文件路径改变用户选择范围。普通 JS/TS 路径规则保持原行为。

Vue 此次支持候选发现，不自动证明修复：内置和本地 SAST 零发现的复查保持不确定，直到建立完整块、语言及模板语义的证明。模板安全、跨脚本传播、全程序可达性和生产可利用性都不由本轮验证保证。原有 Java/Python 原生有界分析及 Go SQL 两条调用边范围保持不变。
