## 实际改进

- Java：补上唯一同参数数量的本地构造器及显式对象字段传递；对有已解析框架注解的具体类型服务字段保留类型引用。
- Java：增加已绑定 JDBC 接收者的 `queryForMap`、`queryForRowSet` 等方法；Statement 与 JdbcTemplate 的方法集合分开。
- Java：补上 Commons Codec Base64 编解码往返及 String 构造器的值传递。编码中间值不会无条件被当作已解码 SQL 载荷。
- Python：解析包内相对导入、父包相对导入、关键字专用参数和部分参数转发；拒绝重复、缺失或多余参数形成的无效调用链。
- 证据：返回值链中增加实际被调用函数的位置，不只记录调用者；来源和危险操作在同文件时，也能保留中间跨文件路径。
- 误报门槛：Python 路径扩展只默认输出有已解析跨文件调用证据的结果；先前被拒绝的宽泛单文件路径扩展、Java 路径及命令扩展仍为实验项。

核心静态规则仍为 55 条、47 条默认启用；8 条 Java 实验规则没有被批量开启。
独立数据流提供方版本为 1.1.0，拥有 6 个规则身份，默认选择 Java SQL、Python SQL、Python 跨文件路径 3 个规则。
跨文件路径子集不能被说成完整路径遍历覆盖，未输出结果不证明路径安全。
公开基准中当前提供方结果保留 Java 14 条、Python 4 条跨文件证据链；这不是全部项目可达性覆盖。
