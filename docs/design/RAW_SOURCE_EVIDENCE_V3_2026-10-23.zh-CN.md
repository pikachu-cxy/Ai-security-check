## 目标与范围

后续新任务采集的源码、配置片段和扫描证据直接保留原文，包括代码中嵌入的凭据。
从采集、固定版本存储、详情、AI 复核、反馈、影响评估到最终报告，不再替换密钥值，
也不整行遮盖凭据命中位置。新证据策略为 v3，复核协议仍只执行 v3。

已保存且经过遮盖的旧正文无法还原，不补采、不重建旧基线，也不开展 v1/v2 功能改造。
Runtime 自身的 API key、认证及会话凭据保护继续保留。原文证据与运行诊断分开处理。

保留工作区路径约束、文件大小和响应预算、归属校验、版本和哈希校验、过期失效、
输出转义及控制字符处理。源码和扫描器文本仍是不可信数据，不能作为执行指令。
向外部模型发送代码仍需显式授权；提示文本明确说明发送原文及其中的凭据。
