
## v0.3.11：减少临时产物混入源码检查

- 给开发 Agent 提供统一临时文件规则：一次性脚本、模拟项目、下载包和日志默认放在工作区外的系统临时子目录，用户无需选择或配置临时目录。
- 支持同一任务声明已知生成产物，收尾时有界排除并保留原始观察记录与排除依据；显式编辑记录和 Git 已跟踪源码优先保留。
- 正式测试代码及新建、尚未被 Git 跟踪的源码仍按项目编辑观察规则检查；不把整个测试目录排除，不根据文件名猜测源码用途。
- 保留具体扫描失败错误码，修复 Windows 长路径文件枚举不完整导致的扫描输入异常。

采用 focused 精简发布验证，保留合规、包完整性、Windows/macOS 定向回归及三平台原生包验收。开发 Agent 的目录规则属于行为约束，不是进程沙箱，也不承诺自动接管所有工具输出。

### 安装本次正式包

下载本页对应平台完整包和配套 SHA256，核验并完整解压，再在包的上级目录执行：

Windows PowerShell：
```powershell
.\security-check\security-check.exe install codex
```

macOS：
```sh
./security-check/security-check install codex
```

Cursor 用户将末尾的 `codex` 替换为 `cursor`。安装后重启编辑器，并核对实际 Runtime 版本为 0.3.11。
独立 macOS 自动安装发行和旧文档的一键安装地址可能仍指向旧版本；获取本次版本请使用本 Release 的平台包。
