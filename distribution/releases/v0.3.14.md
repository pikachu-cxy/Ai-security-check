## 0.3.14

### 替换发行：Codex 与 Cursor

- 修正 PowerShell 路径变量、Get-Content 赋值与常量切片读文件被当作未知写入的问题；可确认只在项目外删除的字面量清理命令跳过开发采集。
- 监听通知先核对当前项目目录边界，外部路径和相邻同前缀目录不记录；项目内真实写入、混合未知脚本与无法核验路径继续检查。监听表示时间窗内变化，不证明写入者。

- 本次发行支持 Codex、Cursor；WorkBuddy 暂不支持，文档站隐藏安装入口。
- 修复原生包风险管理后台启动失败：冻结包使用构建标识，不再读取包内不存在的 Python 源文件。链接缺失时报告直接说明覆盖限制，不显示 `session_url: null`。
- Windows 安装、配置、状态与组件缓存统一至用户主目录 `.asr`，安装时安全迁移旧数据并保留原件；正常重复安装不增加扫描、探测或固定等待。
- 文档站优先提供复制给 Agent 的一句话安装请求，手动安装为备用；安装结果与宿主重连验证分别说明。
- 三平台各构建一次，仅运行原生安装、身份、MCP 和后台页面冒烟验证；全部通过后备份并替换原 0.3.14 资产和标签，失败恢复原发行。

- 修复父 Agent 收尾遗漏开发子 Agent 改动的问题，本轮记录合并后复用原扫描、复核和整批报告流程。
- 额外修后复查默认关闭；修复编辑照常触发普通开发检查及已开启的复核/业务审计，不追加专项复扫。
- Codex、Cursor 共享开发协议和领域服务，保留各宿主授权及接入边界。
- 整批中文报告、醒目漏洞标题、分隔线及会话链接；后台提供分层资源管理、设置与健康监控。
- 本机 Codex 三配置开发、重启修复及只读验收完成；静态复核、审计首次保存。macOS x64 原生包首次、重复及 0.3.13 升级安装通过，设置保留。
- CI 仅执行三平台原生构建与安装、启动、MCP 快速验证，不重复本机开发验收脚本。

验收边界：原生包安装、MCP 与后台页面验收不等于所有桌面版本和模型组合均已验收；本次替换包仍需目标宿主重连确认。不承诺所有模型回复逐字一致或所有短任务审计都与编辑实际重叠。此前 0.3.14 的完整样本、已知旧测试契约失败及构建身份见仓库知识库 RELEASE_0314_ACCEPTANCE.md；替换包的三平台验证见本 Release 配套证据。
