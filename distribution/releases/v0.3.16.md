## 0.3.16

- 业务逻辑审计支持跨语言文件与源码片段。无法定位 Git 变更行时由 Worker 自行取证，单窗可超过 80 行，返回受响应容量约束。
- 业务审计默认关闭。开启后，支持并发的 Codex 默认使用 Planner 和两个 Worker，也可选择标准单 Worker。标准模式可复用同轮已授权且内容未变的证据，提交前返回逐文件修正提示。
- 深度模式轮内复用 Worker。封存结果后，Runtime 将本轮 Worker 名单交给宿主关闭，实际退出以宿主回执为准。
- 风险管理页可按批次查看资产、任务、证据和覆盖信息。macOS 风险页可请求系统写入确认后保存产品设置和处置风险。
- 本机 Windows Codex CLI 连续派发三轮，每轮两个 Worker，并成功续用原 Worker。桌面端显式关闭和并发名额释放仍待验收。

- 更新提醒统一显示「存在新版本是否更新：查看并更新」。打开本机工具更新页后可直接点击「立即更新」，安装前会核对官方发行包。
- 修复跨版本更新与回滚的试启动校验，按已核验目标包比对版本和构建身份。
- 工具更新并入风险后台的「系统管理」，原更新链接仍可直达，切回漏洞列表保留筛选条件。状态读取短时中断会自动重试，确认安装后提示重启编辑器。
