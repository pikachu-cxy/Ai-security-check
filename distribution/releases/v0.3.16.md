## 0.3.16

- 业务逻辑审计支持跨语言文件与源码片段。无法定位 Git 变更行时由 Worker 自行取证，单窗可超过 80 行，返回受响应容量约束。
- Codex 可选深度模式默认派发两个 Worker。计划参数、缺少逐文件审阅回执、行号证据不足分别返回对应诊断。正常完成时聊天报告显示一条审计完成状态。
- 风险管理页可按批次查看资产、任务、证据和覆盖信息。macOS 风险页可请求系统写入确认后保存产品设置和处置风险。
- 深度模式默认关闭。本机 macOS Codex Desktop 已验证预约样例的两项业务发现和完整收尾。Windows Codex Desktop 的完整 Stop 链路待验收。

- 更新提醒统一显示「存在新版本是否更新：查看并更新」。打开本机工具更新页后可直接点击「立即更新」，安装前会核对官方发行包。
- 修复跨版本更新与回滚的试启动校验，按已核验目标包比对版本和构建身份。
- 工具更新页区分检查过期和暂无新版，可手动重新检查。候选过期时提示重新检查，文字回退与可点击链接分别限频。
