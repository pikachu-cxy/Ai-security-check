# Licensing and third-party notices

AI Security Runtime uses a **closed-core, open-ecosystem** licensing model. The Runtime Core is proprietary under the root LICENSE and EULA. Explicitly marked Apache-2.0 components, the public scanner/plugin extension contract, and the `ai-security-core` community rule pack retain their open-source licenses. Future SDKs or specifications are not automatically open source until explicitly marked.

A public repository, downloadable binary, or free tier does not change the Core license. Third-party engines and dependencies retain their own terms and do not grant rights to the proprietary Runtime.

Read the formal files for the version you use; this page is navigation and does not replace or extend them:

- [LICENSE](https://github.com/pikachu-cxy/Ai-security-check/blob/feature/runtime-mvp/LICENSE)
- [Licensing model](https://github.com/pikachu-cxy/Ai-security-check/blob/feature/runtime-mvp/LICENSING.md)

Full bundles should include the matching notices and licenses. Keep companion files rather than distributing only the main executable. Engines, rules, and vulnerability data can have different terms.
