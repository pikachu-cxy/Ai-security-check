# 版本与进度

## 0.3.9 · 正式版

2026-10-21：[v0.3.9 Release](https://github.com/pikachu-cxy/Ai-security-check/releases/tag/v0.3.9) 已公开，三平台正式版完整包对应源码 `fa1a26b`。[成功的发行流程](https://github.com/pikachu-cxy/Ai-security-check/actions/runs/39623506500)完成 Windows/macOS 当前改动的定向回归、合规、包完整性及三平台原生验收，未重复全库回归。完整包与 Mac 独立自动安装分别构建和校验，入口见[下载页](../downloads.md)。

- 支持 Windows x64、Mac Apple Silicon（M 系列）和 Intel，提供配套 SHA256、来源清单和验收证据。
- 自动发现的系统 Semgrep 无法核验执行身份时，在线安装准备独立受管环境，保留原系统安装；离线、显式指定路径及受管组件故障继续保留诊断。Mac 安装脚本使用 `macos-trial-v0.3.9.3`。
- 区分检查工具缺失、执行身份无法确认、OSV 本地漏洞数据缺失、数据过期和更新时间未知；不把检查缺口当作漏洞或安装失败。
- 加强模板表达式凭据脱敏，保留纯变量引用；为源码中的脱敏标记字面量保存定位依据，减少不必要的隐藏变化缺口。旧任务证据不重建。
- 风险说明区分待核实扫描提示与代码复核结果，随用户对话语言表达；已有同范围授权不重复询问，重复检查缺口合并说明。

- 新增一键启动当前 Codex 聊天消耗监控，校验身份后自动关联，结束后一键导出 HTML / JSON 报告 ZIP，无需试用者查找日志。
- 报告区分聊天 token、观察窗口时长、工具累计耗时与并发区间并集；无法可靠拆分的纯开发 / 纯安全 token 保持未知。无基线或记录缺失时说明部分覆盖，不估算费用或虚构节省。
- 监控是可移除的可选模块；失败、停止或缺席不改变核心扫描、任务复核和修复授权，不保存聊天正文或源码。
- 新任务完整保存脱敏长行，超大单行按实际序列化响应大小分片，全部字符交付后才计整行已读；源码哈希、版本、脱敏及容量校验继续保留。
- 原任务、断点和累计交付账本可继续使用；重复读取不重复送出已读片段，旧版已截断前像不补造，保留不可恢复缺口。
- 文件范围扫描、完整项目结果核验复用、紧凑摘要、分页与 MCP 阶段进度继续可用；普通只读查询不因此启动项目扫描。
- GitHub 主 README 和 `/en/` 文档提供英文入口；中英文沿用相同功能、支持、隐私和许可边界。

文档站在对应发行资产公开后部署。实际桌面、Apple 签名和公证仍需独立验收；旧版本的 CI 或桌面记录不代替当前版本验证。以下内容为历史版本记录，不作为当前安装指引。

## 0.3.8 · Developer Alpha

2026-10-20：[v0.3.8 Release](https://github.com/pikachu-cxy/Ai-security-check/releases/tag/v0.3.8)的九项资产已同版本更新。Windows、Mac Apple Silicon 与 Mac Intel 统一使用产品源码提交 `8d5d9a6`，[三平台构建及原生验收](https://github.com/pikachu-cxy/Ai-security-check/actions/runs/39398870803)通过，下载及校验入口见[下载页](../downloads.md)。此前下载过 0.3.8 的用户需重新下载配套文件，安装后重启宿主核对 `build_id`。

- 紧凑扫描摘要、分页查询与简短复核回执成为默认，完整内容仍可显式请求。
- 原生 Agent 证据交接增加完整响应预算，重复及重叠源码共享；延后成员继续待复核，保留原证据身份、复核和修复授权。
- 新增[本地上下文开销监测](../guide/context-cost.md)，区分响应字节和宿主实际 token；Codex CLI 日志解析独立导入，不影响其他 MCP 宿主。
- 本轮相关定向测试 204 项通过、1 项跳过，文档打包契约 13 项通过；字节缩减基准不冒充真实模型 token 节省。

- 工作流指导按需加载、去重，并按版本、摘要和实际构建身份复用已读内容。
- MCP 接通共用扫描阶段进度与计时，区分本次核验、历史扫描和宿主侧未知耗时。
- 支持明确指定工作区相对文件，展示实际范围，不把单文件请求扩大为整项目。
- 完整项目扫描仅在源码、规则、引擎、配置及数据身份等证明有效时复用结果；无法核验或明确要求重扫时重新执行。
- 保留必要复核与修复授权。Windows/macOS、Codex/Cursor 共用核心逻辑，进度显示由宿主能力决定，不沿用旧包的原生或桌面验收结论。
- 修正 wheel 验证脚本对旧指导文案的断言，继续检查当前的编辑授权约束。
- 本次采用精简发布流程，通过 Windows/macOS 相关回归、合规、包完整性及三平台原生验收；未重复执行全库回归。README、下载页、工作流程及 Cursor 指南同步为已发行状态。

- v3 任务复核与风险交付能力，保留基线、改动、处置和恢复链。
- Windows 扫描私有输入长路径处理、Semgrep 短临时目录与有界就绪探测。
- 初始化、发布锁竞争、中断和取消后的恢复；沿原任务恢复已完成结果。

本次发布工程改动修正包验证脚本对新 Skill 布局的过期假设：逐一检查当前受管文件的标准内容，拒绝缺失、修改或退役方法残留，不跳过一致性校验。
