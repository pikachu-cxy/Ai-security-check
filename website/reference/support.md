# 支持状态与检测范围

本页对应 **0.3.10 正式版**。[下载页](../downloads.md)提供发行包、SHA256、来源清单与验收证据。

## 系统与宿主

| 平台 / 宿主 | 当前入口与验证范围 |
| --- | --- |
| Windows x64 | 原生完整包，已完成本次 Windows 定向回归与包验收 |
| macOS Apple Silicon / Intel | 各自原生完整包，分别构建与验收；另有专用 Python 环境自动安装 |
| Codex / Cursor | `install codex` / `install cursor` 接入用户级 MCP、Skill、Hook；Cursor 同步常规工具白名单 |
| WorkBuddy | 项目级 MCP 配置；不承诺自动编辑记录 |
| 其他 MCP 客户端 | 按客户端支持的本地 stdio MCP 格式手动接入 |

当前不提供 Linux 完整包。Codex / Cursor 以本地实际项目根目录为接入入口；远程、多根工作区和各宿主版本需单独验证。CI 原生验收不等于所有桌面版本、模型或企业策略下均可用。

## macOS 安装与验证 {#macos-installation}

[Codex](../guide/editors/codex.md#macos)与 [Cursor](../guide/editors/cursor.md#macos) 页提供自动安装命令。脚本自动识别芯片，固定使用已公开的 `macos-trial-v0.3.10`，校验下载并准备专用 Python。正式原生完整包使用 `v0.3.10`；两者版本相同、来源构建不同，应分别核对 `build_id`、提交和校验值。

自动安装的双架构验证见 [Mac 安装工作流](https://github.com/pikachu-cxy/Ai-security-check/actions/workflows/macos-trial.yml)。真实 Mac 系统策略、首次下载、桌面连接和扫描组件仍按实际结果判断；当前没有 Apple Developer ID 签名或公证保证。

## Cursor 接入与重连

完整安装包括常规工具的精确白名单，但是否需要点击 Run 仍受 Cursor 运行模式、当前用户配置和团队策略影响。MCP 自动执行许可与产品风险修复授权分别生效。

会话由 Hook 提供签名归属，Agent 不需要猜测聊天编号。接入验证除一次开发检查外，还应在重连后只读原检查，确认结果和处置可读。当前用户目录中的配置不会自动转移到另一操作系统账户。详见 [Cursor](../guide/editors/cursor.md) 和[常见问题](./faq.md)。

## 检查范围

### 语言覆盖 {#语言覆盖}

**默认代码引擎为 OpenGrep，使用已安装的 `opengrep-rules` 规则包。** 规则包身份与每次选择、执行结果分开记录，不用一个固定条数代替所有语言覆盖。

| 输入 | 如何理解覆盖 |
| --- | --- |
| Java、Python、JavaScript / TypeScript、Go、PHP | 依据文件类型与规则包选择适用规则，检查结果报告实际执行情况 |
| C / C++、C#、Ruby、Rust、Kotlin、Shell、YAML 等 | 支持类型识别和适用规则选择；有无匹配规则、解析成功与实际执行仍逐次确认 |
| Vue `.vue` | 提取支持的 JS/TS 脚本块；模板、样式和外链脚本不算已覆盖 |
| Java / Python 原生数据流 | 有限调用和数据传播分析；循环、动态参数、跨文件上下文或预算限制可能保留部分覆盖 |
| Go 原生 SQL 与 JS/TS 动态代码补充 | 有限模型下提供候选，不代表全程序证明 |

识别扩展名不等于所有框架与漏洞都能检测。结果中的可用规则、选中规则、已执行规则和文件覆盖分别统计；解析错误、排除项或不支持的语义需保留实际限制。

### 密钥、依赖与配置

- **Gitleaks**：扫描纳入范围的文本中的凭据模式，不保证识别所有自定义密钥。
- **Trivy**：默认依赖漏洞检查；结果依赖可识别清单、版本与有效漏洞数据。适用配置检查单独记录。
- **依赖输入**：包括当前产品识别的 Python、npm/Yarn/pnpm、Maven/Gradle 和 Go 清单或锁文件；不能把底层工具支持的所有生态直接当作产品已覆盖。
- **OSV / Semgrep**：保留兼容或显式调用能力，不属于默认必需扫描链。Trivy 失败不会自动切换 OSV。

没有适用依赖输入时可返回“不适用”；有输入但工具或数据失败时应报告缺口，不能记成零风险。

### 本次检查的边界

默认静态检查覆盖已记录文件，不建立全项目基线。Agent 为审计业务逻辑读取关联文件属于复核范围，不自动扩大扫描。需要整项目扫描或严格前后差异审计时明确提出。

只读历史查询不核验当前磁盘，也不重扫。部分覆盖应区分文件遗漏、扫描器能力限制和编辑观测提示；未扫描无关文件不应被解释为本次任务必须补扫全项目。

## 风险统计与消耗监控

[风险统计](../guide/risk-handling.md)读取本机当前用户的 Codex、Cursor 已保存记录，可按编辑器筛选或一起查看。跨编辑器同一问题可能分别计数；第一阶段不做跨来源合并去重，也不提供云端同步。

[消耗监控](../guide/context-cost.md)是独立可选功能，当前聊天 token 自动关联以 Codex 本机日志适配为准；缺少真实 usage 数据的宿主保留未知。
