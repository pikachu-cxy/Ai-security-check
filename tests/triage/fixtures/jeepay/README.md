# Jeepay-shaped regression data

All snippets are independently authored synthetic/reconstructed shapes. No actual project source, credential, prompt or model response is distributed here. `cases.json` supplies stable input shapes; `ground_truth.json` supplies separate, editable reference labels. A model's response must never populate human ground truth automatically.

Real Jeepay analysis uses the locally stored native scan and bounded redacted EvidencePackets. Its report records structured analysis, hashes and byte counts; it does not persist full prompts or code context. Real-project ground truth starts UNREVIEWED until a human labels it.
